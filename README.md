# Abhi Gupta | Enterprise and Product AI portfolio

Production source for [abhi07gupta.github.io](https://abhi07gupta.github.io/).

The portfolio uses an editorial, evidence-led visual system with oversized type,
framed project surfaces, a sticky case-study narrative, restrained native scroll
motion, and a code-native AI system map. The interaction model avoids forced
scrolling and custom cursors, respects reduced-motion preferences, and remains
fully usable with a keyboard.

The build is dependency-free at runtime and ready for GitHub Pages. It includes
semantic HTML, responsive CSS, accessible navigation and status messaging,
structured metadata, a sitemap, robots rules, a custom 404 page, and direct links
to the public CV, LinkedIn, and four public reference projects. Arial is the only
font family used across the site.

All examples are synthetic or sanitized. The RCA reference uses vendor-neutral
synthetic data. No employer-confidential architecture or private metrics are
published.
