# Abhi Gupta | Public portfolio website

Production source for [abhi07gupta.github.io](https://abhi07gupta.github.io/).

The site is a dependency-free GitHub Pages build with semantic HTML, responsive
CSS, keyboard navigation, reduced-motion support, metadata, structured data,
sitemap, robots rules, a custom 404 page, a reliable contact section, and direct
links to the public CV, LinkedIn, and four GitHub reference projects spanning
Enterprise AI, Product AI, agentic controls, semantic context, and synthetic
autonomous-network RCA. Arial is used throughout
to keep typography consistent across platforms.

All examples are synthetic or sanitized. The RCA reference uses only
vendor-neutral synthetic data. No employer-confidential architecture or private
metrics are published.
